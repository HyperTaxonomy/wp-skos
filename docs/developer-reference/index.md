# WP-SKOS Developer Reference

For developers and integrators reading WP-SKOS data or extending it.

- **[Concept URIs & JSON-LD](concept-uris.html)** — content negotiation, vocabulary property declarations, and the JSON-LD for concepts, schemes and collections.
- **[Document Search](document-search.html)** — the concept-queryable document search endpoint, relevance ordering, pagination, and peer-site documents.
- **[Skosmos REST API](skosmos-rest-api.html)** — all endpoints at `/skosmos/rest/v1/`, for software written against Skosmos's API and other SKOS clients.
- **[Filters](filters.html)** — changing the AI agent guide and turning off the export.
- **[HyperTaxonomy Integration](hypertaxonomy-integration.html)** — the HyperTaxonomy functions and feature flags WP-SKOS uses, and how it caches and invalidates documents.
