# WP-SKOS User Guide

For site owners: what WP-SKOS publishes about your taxonomies, and how to share and import vocabularies. To install it and enable your first taxonomy, start with [Getting started](../#getting-started).

- **[Concepts & Data Model](concepts.html)** — how terms and taxonomies become SKOS concepts and schemes, what changing a slug does to a concept URI, and multilingual labels.
- **[AI Agents & Export](ai-agents.html)** — the generated `llms.txt` guide and API catalog, the whole-vocabulary export, and loading it into a triple store.
- **[Python Converter](converter.html)** — converting a SKOS file into HyperTaxonomy and TermConnect imports.
